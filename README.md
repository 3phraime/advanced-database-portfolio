# ShopSmart — E-commerce and Inventory Management System

## Overview

ShopSmart is a proposed e-commerce and inventory management system developed as the case study for the MIT 8103 Advanced Database Systems practical portfolio.

The system represents an online retail business that manages products, customers, orders, inventory, payments, and deliveries. Its purpose is to explore how database technologies can support reliable transaction processing, efficient data retrieval, accurate inventory management, and the handling of growing operational data.

## Problem Statement

E-commerce businesses must maintain accurate product and inventory records while processing customer orders, recording payments, and tracking deliveries. These operations require reliable data relationships, appropriate integrity constraints, efficient queries, and safeguards against conflicting updates.

ShopSmart provides a practical scenario for investigating these database challenges and evaluating appropriate database design and management techniques.

## Project Objectives

The project aims to demonstrate the application of advanced database concepts to a realistic business scenario through the following activities:

1. **Database Design and Modelling:** Develop a relational database schema with appropriate entities, relationships, keys, constraints, and normalisation.
2. **Query Processing and Optimisation:** Develop SQL queries, examine execution plans, evaluate indexing strategies, and analyse query performance.
3. **Transactions and Concurrency:** Investigate transaction integrity, commit and rollback behaviour, isolation, and concurrent inventory operations.
4. **NoSQL and Advanced Data Models:** Explore an appropriate alternative data model for selected e-commerce data and access patterns.
5. **Distributed and Cloud Databases:** Examine or implement suitable distribution, replication, availability, consistency, or cloud deployment strategies.

## Scope

The proposed system covers customer and product records, product categories, inventory, customer orders, order items, payment records, and delivery information.

The implementation will focus on database design, data integrity, querying, transaction processing, performance analysis, and database architecture. A complete commercial storefront, real payment gateway, and production logistics integration are outside the initial scope unless subsequently justified by the assessment requirements.

## Technology Approach

The relational database will serve as the primary data store. An appropriate NoSQL model and a distributed or cloud database approach will be evaluated in relation to the system's requirements.

Specific technologies and implementation choices will be documented alongside the relevant portfolio activities.
